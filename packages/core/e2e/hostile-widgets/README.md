# Hostile widget qualification (FORMA-129)

Run `node packages/core/e2e/hostile-widgets/run.mjs` after building core. The actual production IIFE is served over local HTTP with nonce CSP and enforced Trusted Types, then mounted through `mountMarkup(..., {tier: 'reviewed', grants})` in Chromium. No unsafe-eval, unsafe-inline or default Trusted Types policy is added. `--only=...` writes an explicitly partial pilot and cannot claim the complete matrix.

The catalogue has 1,950 hostile cases: `(22 literal values × 23 live value contexts + 13 hostile expression programs × 10 expression contexts + 7 executable/document URL schemes in data-fetch + 7 raw-markup cases) × 3 profiles`. Four of the value contexts are the URL sinks (`href`, `action`, `src`, SVG `xlink:href`) written as static attributes: the mount renders a benign URL, and an `update()` patches the payload into the element it keeps (FORMA-276). By then the parser has written a NUL in the markup as U+FFFD, so in those four the NUL payload is an ordinary relative URL and is kept, as the parser made it. Explicit empty grants and a typical GET-only `/api/widget/` grant without cookies remain root-confined. The all profile explicitly grants DOM, navigation and a finite local fetch policy. Every hostile case requires an active adjacent binding, its exact inert value or coded refusal, zero executions, zero unauthorized HTTP requests and zero outside-root reads. The report records each executed ID; missing/duplicate cases fail.

The data-fetch mini-DSL takes a URL, not an expression. It receives the seven syntactically supported non-HTTP script/document schemes; arbitrary expressions or embedded newlines are not presented as supported URL syntax. The newline payload remains in all 23 live value contexts; the mini-DSL parser would otherwise leave it inert. Model and persist bind assignable paths and receive all22 values through those paths. Nine additional explicit-mount controls verify the exact nine runtime exports, inert server/injected markup, and actual omitted-grant refusal/DOM confinement in both compiled and reviewed tiers across all three profiles. The 30 separate capability controls exercise actual method, prefix, normalized-dot path, encoded separator, cookie, redirect and second-local-origin boundaries, root traversal/selector access and activation dispatch. They record deliberately granted authority separately: an all-grants outside read is permitted, while none/typical must never read outside.

The independent observers count execution, secret-bearing native selectors/attribute reads and all local HTTP requests except the exact document/runtime resource loads. Positive controls increment each observer, including a real unexpected-path404, and verify that an untrusted HTML sink is refused by actual Trusted Types. The activation observer listens at the actual dispatch target: Chromium's synthetic submit does not reach the ancestor observer in this fixture. Images/parser events run while the tree remains mounted. Real page errors are fatal.

`node packages/core/e2e/hostile-widgets/qualify-guard.mjs` removes exactly the actual selector-grant refusal from a scratch copy of the built runtime. The same selected cases must pass before and after, and fail under the mutant because the real observer sees an unauthorized outside-root read. It preserves artifact/report hashes and proves the production runtime was unchanged. Timeout, disconnected mutation anchor or an unrelated exception cannot satisfy the mutation control.

`probe-provenance.json` authenticates the historical93 mutation records and all 159 current security records (299 total current records at this source revision), retaining an explicit disposition for every original ID. It also authenticates all260 original A2 records:19 removed-API/path probes are retired with individual reasons,14 are re-anchored or have obsolete test attribution corrected, and eleven current-only probes cover explicit default authority, captured disposal, diagnostic attribution, the surviving development hint, and current typed reconciliation/adoption paths. Retired probes never count as current mutation kills. These are mutation instructions, not93 payload strings. Lifecycle, frame and structural mutations retain their named existing suites; this matrix does not claim to execute every historical mutation. The expression campaign and the separate nightly mutation run cover their respective portions.

Original failures remain in the release work directory and committed runtime-fix archives. The corpus found two real runtime defects: granted fetches followed redirects outside the authorized prefix, and a removed list template's nested controls were bound against the wrong scope. Those are separately reviewed production fixes. Oracle calibration retained the failures and followed existing contracts: SVG data is admitted only in the image context; NUL URLs are refused; nested Function calls, unresolved import identifiers and block-bodied arrows have distinct exact refusal codes. No security observation was relaxed.

The JSON report records Node/browser versions, commit/clean status, actual runtime, catalogue and harness-source hashes, policy, exact observations and elapsed time. The original 1,665-case run passed with30 capability controls before the additional21 fetch-scheme cases and unexpected-path observer were added. The expanded qualification is recorded separately. R17 and the nightly expression job execute the full matrix plus the guard mutation; their output is evidence, never a substitute for the production bundle hash.
