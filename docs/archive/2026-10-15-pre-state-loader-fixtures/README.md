# Loader fixtures before required state contracts

These original fixture bytes and their generator are retained from `1e5a1c4`. The old good module contains an island without required section 10, so the current native reader correctly refuses it. The active generator now uses an explicit declared empty contract and computes the corrupt opcode offset from the section table; the same five corruption refusals remain. Active manifest SHA-384 values follow the regenerated bytes. This archive is historical evidence and is not a current acceptance corpus.
