# FORMA-101 strict subset migration

These files preserve their exact contents before FORMA-101, based on F1 commit
`215e61f52013220be493dfb319f78bdbcfa1889b`. The current
[subset](../../../packages/compiler/docs/subset.md) replaces warning-only SSR
publication with mandatory refusal. Historical placeholders cannot establish a
native product. No FMIR format or valid-page encoding changes merely from the
publication gate.

The adjacent [placeholder helper](../FORMA-101-placeholder-helper.md),
[warning-mode test](../FORMA-101-warning-mode.md) and
[unproved list sources](../FORMA-101-unproved-list-sources/README.md) preserve
superseded executable inputs. Callable-but-native-unproved lists now refuse with
BUILD-610; BUILD-616 continues to mean a provably non-callable source. The live
near misses use real closed local rows or declared handler arrays.
