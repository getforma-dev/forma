600-second bound: rank-19 p95 is 748.73 seconds. Its observations remain unchanged.

guard rejected an ordinary setup-generated Python cache. A narrowly corrected
successor pilot completed once in 493.39 seconds, with all 32 original stages and
280 core files accounted for. That is a development functional result, **not an
N7 sample, measured distribution or release approval**.

The previous native-group increment measured 12,287 bytes against a 12,288-byte
ceiling. Runtime changes cannot inherit that one-byte margin. Standalone entry
gzip observations do not establish the final group size. Run a fresh comparison
from the actual sealed archives using the existing compressor, baseline and
unchanged limits; investigate a failure rather than raising the ceiling.

Published RC3 has no credited active soak. Product and harness changes require
a settled, qualified successor and its own required hosted burn-in. Idle elapsed
time, the scheduler pilot and earlier releases cannot supply those seconds.
