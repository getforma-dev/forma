## Changes prepared for RC3

The source changes do not change router runtime behavior or size/performance
ceilings. The coordinated version projection updates all eight packages and
starter locks/seeds; those source strings are not publication evidence.

1. **Finite npm placeholder record.** A public `@getforma/router@0.0.0-stage`
   holding archive was observed during the original router publication. The
   [closed plan](npm-provider-placeholder-router.json) pins that exact npm
   identity, provider metadata/time, canonical URL, 364-byte archive and member
   hashes. It permits a receipt only on **v3.2.0-rc.3**. This is an association
   with the original publication, not an invented explicit staging event.
   Check authenticates the original metadata/bytes before publishing; record
   authenticates the actual preparation and recorder executions and retains the
   canonical preparation file/manifest durably. A later consumer authenticates
   the real host tag/source/run, DS12 pointer and receipt before inventory use.
   The receipt is inventory-only: no product, support, performance or soak
   qualification. Unknown stubs, changed data, unavailable archives and duplicate
   claims still fail. Router's historical baseline stays empty. See
   [the reconciliation contract](REGISTRY-RECONCILIATION.md).
2. **Remove two duplicate operations in three harness files.**
   [`core-raw-package.test.mjs`](../../scripts/core-raw-package.test.mjs) checks
   the existing traced positive TypeScript result instead of compiling the same
   positive again. Four positive modes, CommonJS consumers, expected errors,
   negative controls and packed path/`typesVersions` checks remain. The
   [native proof launcher](../../scripts/run-router-native-proof.mjs) delegates
   the single fresh fixture build to [size measurement](../../experiments/forma-router-native/measure-size.mjs),
   which clears stale outputs, retains build diagnostics and verifies both
   current/next manifests and referenced products before Cargo/browser execution.
   No work moves outside the R17 timer, and no check, threshold or worker changes.
3. **Current release documentation.** Stable 3.1, published RC2 and unpublished
   RC3 have separate instructions. Historical changelog entries and the original
   57-row [router qualification campaign](../design/router/qualification-3.2.md)
   keep their actual measured identities.

Focused source controls for the placeholder passed 310 checks; the independent
workflow self-test passed 586 after restoring the required build prerequisites.
The three-file harness change separately preserved 13 TypeScript failure controls,
eight native failure controls and passed an actual 30-case Chromium native proof
