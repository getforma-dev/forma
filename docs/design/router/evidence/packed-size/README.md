# Installed-archive native size qualification

The complete installed-package closure is **40,713 gzip bytes**. The ordinary full-document controls are 28,432 bytes for A and 28,433 for B; each published 3.1.0 control is 28,457 bytes. The unchanged paired contract therefore reports **12,281/12,288 bytes** at the worst route, with **7 bytes remaining**. The group ceiling remains 65,536 bytes.

`packed-size-summary.json` authenticates the full durable outer receipt, all eight sealed archives and the four installed JavaScript products actually executed. Every archive-owned installed file was compared with an extraction of its pinned archive before building; all installed files, nested dependency files and local `.bin` link targets were checked again afterward. Nested dependencies are bound to the original authenticated consumer lock. Public module resolution is restricted to that isolated consumer, with real paths and hashes recorded. No original workspace Forma runtime code is reachable through the mapped package roots.

The wrapper runs the unmodified authored `measure-size.mjs`, `build.mjs`, app/client inputs and size-contract helper from sealed commit `9d4aafee0c99cde4faff3f39a8fca2705e70a398`. Its separate sparse measurement view intentionally reports `sourceDirty: true`: package paths and node_modules are mapped to installed archives and an explicit staging marker documents this. The outer receipt checks all authored hashes against Git, rechecks all eight archive identities and proves the original packed browser proof and its output files were unchanged. The measured bootstrap and worker hashes also exactly match the 90-case packed native proof.

The published-core baseline is the same pinned 3.1.0 archive, SHA-256 `312149d7c863f54776bc5d0eb78fa920f009dc7e5867352535c877e16d4610b7`. No baseline, code or limit changed for this measurement. The source-size and installed-size results happen to be identical; they remain separate receipts.

`attempts.json` preserves three wrapper preflight failures and one passing replay that lacked Cargo metadata. The final replay includes that unchanged metadata and emits no compatibility warning. A deliberately corrupted **copy** of the core archive was refused before any clone/build command; its negative receipt is retained. Original archives and proof files were untouched. This qualification ran only after the native timing campaign released its quiet window. It is local development qualification, with no publication or new whole-P17 claim.
