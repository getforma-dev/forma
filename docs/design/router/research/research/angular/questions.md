# Angular question ledger and reconstruction tests

This ledger answers the questions that most affect an implementation. “Source” means the pinned commit `ecaec13db4fde7ceb0104105ee356bf00596f3d6`, not a test we executed. “Browser” means only the Chromium experiment in [browser-angular.json](../../evidence/browser-angular.json). “REA” means the bounded static campaigns in [rea-summary.json](rea-summary.json). The [main report](report.md) develops these answers in context.

## Identity and evidence

1. **Where is the actual implementation?** Both Angular Router (`packages/router`) and angular.dev (`adev`) are in [angular/angular](https://github.com/angular/angular). The page footer identifies v22.2.3+sha-ecaec13; that prefix resolves to the full pinned commit above. The snapshot, guide Markdown, license, deployed HTML, 12 advertised JS assets, hashes, and analysis receipts are retained. This identifies a study snapshot; it is not an independently reproducible build verification. See [sources.json](sources.json).

2. **Where is the docs app hosted?** The repository declares Firebase Hosting configuration, including a target, static build directory, cache rules, and fallback rewrite. That supports an intended hosting configuration. We did not access the live deployment account or prove every network layer/provider. Source: [A33](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/firebase.json#L1-L86).

3. **Is the docs site actually client routed?** Yes for the sampled guide link in Chromium 155: document ID/time origin remained constant, the route/title/H1 changed, and the browser requested an HTML content fragment and an image rather than a document. Back reused the document. With JS disabled, the anchor loaded a new document. This is narrower than “every URL and browser behaves identically.” Browser: [experiment](../../evidence/browser-angular.json).

4. **Can REA recover the complete router or route table from these minified bundles?** Not in this bounded run. It parsed one selected source in each of two campaigns, produced useful static import/exposure relationships and provenance, but its semantic graphs truncated and its route inventory found only one low-confidence candidate. Eleven assets in each inventory were outside that run's selected scope. Complete algorithms and configuration came from pinned source reading; actual execution came from the browser experiment. REA: [summary](rea-summary.json).

## URL recognition and navigation

5. **What must the URL parser preserve?** Structural outlet groups, ordered segments, matrix parameters, separate repeated query values, and fragment state. Query `+` decoding and path decoding are different contexts. Preserve encoded slashes until the grammar decides their role; this site's custom pre-parser deliberately deviates to align with hosting. Source: [A01](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/url_tree.ts#L472-L498) [A02](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/url_tree.ts#L572-L642) [A30](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/core/services/routing/adev-url-serializer.ts#L15-L25) [A38](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/url_tree.ts#L810-L884).

6. **What does “first match wins” actually mean?** The first route configuration whose recognition succeeds for the relevant branch. A matching prefix can still fail through its child routes, allowing a later candidate. `canMatch: false` also permits fallback; activation denial cancels instead. Source: [A04](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/recognize.ts#L251-L284) [A05](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/utils/config_matching.ts#L54-L118).

7. **Are routes limited to flat paths?** No. Parent/child snapshots, named outlets, empty paths, positional parameters, redirects, and wildcard rules are part of the recognition model. In this snapshot the default matcher allows one `**` wildcard position with prefix/suffix matching, not multiple wildcard segments. Source: [A06](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/shared.ts#L153-L218) [A04](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/recognize.ts#L251-L284).

8. **How are redirect loops bounded?** Absolute redirect restarts increment a counter; exceeding 31 throws in development mode and disables redirects in production. Redirect is a distinct control outcome, not a component that briefly renders. A reconstruction should choose and test its own explicit redirect budget rather than copy a magic constant. Source: [A03](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/recognize.ts#L120-L172).

9. **What keeps a slow earlier navigation from overwriting a later one?** Transition ownership: outer switching, navigation IDs, an AbortController, and continuation checks for synchronous re-entry. An aborted signal alone cannot prove that every Promise stopped. The implementation checks whether the transition still owns its side effects. Source: [A08](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/navigation_transition.ts#L447-L985). Upstream tests cover navigation initiated during activation, guards, and resolver-start events; we inspected these tests but did not run Angular's suite. [A39](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/test/integration/navigation.spec.ts#L478-L612).

10. **Are same-URL requests always ignored?** The default can skip them, while reload configuration can run the pipeline again. This is independent from guard/resolver rerun policies and component reuse decisions. “Reload URL,” “reload data,” and “recreate component” are three separate contracts. Source: [A08](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/navigation_transition.ts#L447-L985) [A19](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/utils/preactivation.ts#L176-L205) [A15](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/route_reuse_strategy.ts#L117-L165).

11. **Does a link click always call pushState?** No. The usual History API manager pushes/replaces as configured, but current docs source opts into a Navigation API adapter when available and excludes Firefox in this snapshot. The sampled Chromium click emitted Navigation API `push` and no wrapped history push/replace calls. Source: [A09](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/statemanager/state_manager.ts#L193-L325) [A22](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/routing/router_providers.ts#L32-L89) [A11](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/statemanager/navigation_state_manager.ts#L402-L541). Browser: [experiment](../../evidence/browser-angular.json).

12. **Why is cancelling Back harder than cancelling a link?** With History API traversal the browser cursor may already have moved before guards finish. The manager has committed-state snapshots and page IDs to restore consistency; computed cancellation can move the cursor in the opposite direction. Do not push a new entry during traversal. Source: [A09](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/statemanager/state_manager.ts#L193-L325). Upstream test definitions: [A40](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/test/computed_state_restoration.spec.ts#L45-L235); they were not executed here.

13. **Which anchor actions should stay native?** RouterLink preserves nonprimary/modifier clicks and targets other than `_self`; it retains real hrefs. Navigation interception also excludes downloads, cross-boundary/noninterceptable navigation, and reloads where appropriate. The generated-HTML viewer has its own anchor helper, with different edge handling, so it should not be treated as a universal copyable click interceptor. Source: [A07](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/directives/router_link.ts#L480-L533) [A11](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/statemanager/navigation_state_manager.ts#L402-L541) [A27](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/shared-docs/components/viewers/docs-viewer/docs-viewer.component.ts#L355-L399).

## Data, code, and component identity

14. **When do guards, data, code, and DOM run?** After recognition come deactivation/activation guards, traditional resolvers, lazy component loading, target-state creation, optional route resources, optional view transition, outlet activation, and successful completion/title updates. Lazy child-route configuration can load earlier during recognition because it is needed to determine the branch. URL commit timing depends on the browser adapter and configuration. Source: [A08](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/navigation_transition.ts#L447-L985) [A14](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/router_config_loader.ts#L40-L110).

15. **Do all Angular loaders run in parallel?** No. Traditional resolvers process selected route snapshots in order while resolver keys within one route can execute concurrently. Separate developer-preview route resources support concurrent blocking resources across routes and nonblocking resources; the docs app's inspected providers do not enable them. Source: [A13](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/operators/resolve_data.ts#L28-L126) [A20](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/provide_router.ts#L906-L956) [A21](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/operators/setup_and_run_resources.ts#L28-L215) [A22](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/routing/router_providers.ts#L32-L89).

16. **How does this site get the next document body?** Generated route metadata installs a `docContent` resolver. `ContentLoader` fetches `assets/content/<path>.md.html` when no other extension is present. It caches a Promise per normalized path, keeps 404 failures, and evicts other failures. The browser sample fetched exactly that content format. Source: [A24](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/shared-docs/utils/navigation.utils.ts#L94-L152) [A25](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/core/services/content-loader.service.ts#L15-L46).

17. **Does cancellation stop the content network request?** Not established by this experiment. The Promise cache means cancelling one router subscription is not proof that the originating HTTP work was cancelled. Source supports separate result ownership and shared work. A held-response experiment would be needed to establish request cancellation and cache settlement in this deployment. Source: [A25](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/core/services/content-loader.service.ts#L15-L46) [A08](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/navigation_transition.ts#L447-L985).

18. **What is reused during navigation?** Default route reuse compares route configuration identity; it does not simply compare component class names or URL strings. Parent shells can persist while children change. Docs routes can share a component type yet have distinct route objects. A tutorial-specific strategy deliberately broadens reuse. Source: [A15](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/route_reuse_strategy.ts#L117-L165) [A16](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/operators/activate_routes.ts#L1-L243) [A23](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/routing/routes.ts#L19-L164) [A31](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/features/tutorial/tutorials-route-reuse-strategy.ts#L14-L41).

19. **What DOM transformation occurs?** Angular outlets own routed component instances. Inside the docs component, a viewer sets its content container's generated HTML and wires examples, anchors, and other interactive content. This is a controlled fragment lifecycle inside a component router, not a generic head/body swapper. Source: [A26](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/shared-docs/components/viewers/docs-viewer/docs-viewer.component.ts#L87-L139) [A27](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/shared-docs/components/viewers/docs-viewer/docs-viewer.component.ts#L355-L399).

20. **Is preloading the same as caching?** No. Loader caches share route code promises/results; router preload strategies schedule optional code loading after navigation; HTML modulepreload hints and browser caches are separate; the app content cache stores document Promises. Inspected docs providers do not enable `withPreloading`. Source: [A14](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/router_config_loader.ts#L40-L110) [A17](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/router_preloader.ts#L60-L198) [A22](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/routing/router_providers.ts#L32-L89) [A25](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/core/services/content-loader.service.ts#L15-L46).

21. **Does this router supply form actions and mutation invalidation?** Traditional guards/resolvers are not a general form submission/action protocol. Applications own mutation services and data refresh policy unless they adopt an additional facility. Rerun policies for resolvers are configurable; query-only changes do not universally reload data by default. Source: [A13](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/operators/resolve_data.ts#L28-L126) [A19](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/utils/preactivation.ts#L176-L205). This is an architectural distinction, not a claim that Angular applications cannot build such features.

## Browser experience and server contract

22. **When can scroll restoration happen?** After route/render work has produced suitable layout, with ownership so stale scroll callbacks do not move a newer page. The library emits scroll-related behavior; the docs app implements its own delayed scroller with responsive offsets and disables native history restoration. Nonzero-position restoration was not measured in the browser sample. Source: [A18](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/router_scroller.ts#L55-L165) [A28](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/app-scroller.ts#L44-L119).

23. **Does updating the title guarantee accessible focus?** No. The app has title/canonical policies and a skip-to-main action. Focus remained BODY in the sample. A dedicated keyboard and assistive-technology experiment is required to judge route-announcement behavior. Source: [A32](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/core/services/a-dev-title-strategy.ts#L23-L58) [A37](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/app.component.ts#L57-L87). Browser: [experiment](../../evidence/browser-angular.json).

24. **Does client routing eliminate SSR, deep-link, or base-path work?** No. The initial page and no-JS navigation rely on useful server HTML; the app hydrates it. URL normalization must agree on both sides. `<base href="/">` affects script and anchor resolution. Hosting configuration supplies a fallback, while application routes/error handling decide displayed outcomes. Source: [A29](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/app.config.ts#L30-L59) [A30](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/core/services/routing/adev-url-serializer.ts#L15-L25) [A33](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/firebase.json#L1-L86).

25. **What is the error contract?** Cancellation, redirect, ignored navigation, and failure are separate results. This docs app maps HTTP navigation errors to `/404` through its configured handler; that is an application decision rather than a universal router rule. Server authorization remains necessary independently of client guards. Source: [A22](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/adev/src/app/routing/router_providers.ts#L32-L89) [A08](https://github.com/angular/angular/blob/ecaec13db4fde7ceb0104105ee356bf00596f3d6/packages/router/src/navigation_transition.ts#L447-L985). Official [guard guide](https://angular.dev/guide/routing/route-guards).

## Rebuild verification matrix

These are focused acceptance cases for a future reconstruction. They are proposed tests, not claims that the research ran them or that the shared reference router already implements every Angular feature.

| Area | Fixture or action | Required invariant |
| --- | --- | --- |
| URL grammar | `/a%2Fb?tag=x&tag=y&space=a+b#heading` | Path decoding, repeated query values, space rules, and fragment remain distinct. Host normalization is documented. |
| Base path | Deploy under `/docs/`; click relative/root-relative/fragment URLs | Only app-owned paths are intercepted; generated URLs remain inside the intended base. |
| Ordered matching | `/users/new`, `/users/42`, matching parent with unmatched child | Static precedence and fallback match the declared route-order contract. |
| Nested outlets | Empty parent, named outlet, nested parameters | Parent context and view placement are deterministic; unsupported grammar is rejected rather than silently misparsed. |
| Input edge cases | Malformed `%`, `__proto__` outlet, high numeric keys, empty matrix segment | Parser errors are controlled; user keys do not change prototypes or allocate disproportionate backing stores. |
| Redirects | Relative, absolute, guard redirect, loop, long chain | Redirect count is bounded and a chain cannot commit stale intermediate content. |
| Ownership | Slow A, fast B; A resolves last | B remains current; A cannot mutate title, URL, DOM, focus, or loading indicator. |
| Re-entrancy | Guard/event callback starts C while B cancels A | Only C owns the final commit. Terminal events settle exactly once per transition. |
| History | Push A→B→C, Back, Forward, replace, blocked Back | Traversal adds no entry; cancellation restores intended URL/view/cursor consistency. |
| Links | Ctrl/Cmd/Shift click, middle click, download, target, cross-origin, same-page hash | Native browser affordances remain usable. |
| Data | Parent data, parallel keys, empty resolver, rejection, same-URL/query-only | Loading, cancellation, inheritance, and revalidation policy are independently observable. |
| Cache | Repeat path, concurrent same path, cached404, transient500, release change | Cache keys/lifetimes are deliberate; failed transient requests can retry; release freshness is defined. |
| Identity | Change params on same route; same component on different routes; custom persistent view | DOM/component state follows declared identity and cleanup rules. |
| Scroll/focus | Scroll deep, navigate, Back; late image; keyboard route change | Position restoration waits for layout and cannot race newer navigation; focus behavior is explicit. |
| Initial/server | Hard reload nested path, JS disabled, unknown route, encoded slash | Server result agrees with the client; useful fallback and intended status/error behavior are preserved. |
| Adapter fallback | Navigation API enabled/disabled/unsupported | Shared transaction semantics survive browser-adapter selection. |

## Questions deliberately left open

- **Cross-browser scope:** no Firefox/Safari/browser-version matrix, mobile viewport matrix, or app-base deployment variant was executed. The source has a Firefox exclusion; the investigation did not independently reproduce its linked bug.
- **Races in the deployed site:** no throttled/held request, fast repeated click, aborted browser navigation, resolver failure, or guard-blocked traversal was forced. Source and upstream tests explain intended behavior; runtime proof remains separate.
- **Freshness and memory:** no long session measured Promise-cache growth, detached-view memory, script cache pressure, or deployment rollover behavior. The inspected content cache has no visible capacity/TTL policy.
- **A11y and layout:** focus BODY is one observation, not a full accessibility audit. Nonzero scroll restoration, late layout shifts, screen-reader announcements, and view-transition reduced-motion behavior remain unmeasured.
- **Artifact equivalence:** live HTML and selected assets are hashed, but the source was not rebuilt to prove byte identity with the deployment. No source maps or full lazy-chunk graph were required for this study.
- **Production compatibility:** the reconstruction recommendations do not promise Angular API or URL grammar compatibility. A Forma implementation should explicitly select the contracts it needs and validate against its own runtime/island lifecycle.

These unknowns identify the next experiments if implementing a production router; they do not prevent understanding the architecture established by the retained evidence.
