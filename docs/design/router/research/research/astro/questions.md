## Experiments still required before a production reconstruction

These questions cannot be answered by static source or the selected documentation navigation. They are a focused test backlog, not missing source discovery:

1. Do Forma islands defer unmount across moves and accept updated server props without duplicate hydration? Test actual Forma renderer contracts with a persisted input, canvas, and framework island.
2. What happens when a deploy changes island serialization or script IDs while an old tab stays open? Test old runtime/new HTML and missing hashed assets against a defined compatibility policy.
3. Can interruption during custom loader/style readiness/animation leak detached trees or execute scripts from a stale page? Use deterministic delayed responses and counters.
4. Does a POST that succeeded server-side but lost its response recover without duplicate mutation? Specify idempotency and fallback before implementing retries.
5. What do keyboard users and screen-reader users experience after normal navigation, back, hash changes, and persisted focus? Exercise real assistive technology and reduced-motion settings.
6. Which current Chromium/Firefox/WebKit behaviors differ for native View Transitions, `moveBefore`, media initialization, history scroll, CSP, and module scripts? Feature-detect mechanisms and run a browser matrix.
7. Can repeated navigation preserve bounded listener/subscription/cache counts? Measure after hundreds of swaps, including custom-element teardown and rerun scripts.
